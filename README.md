# 🌍 GreenEarth - Environmental Awareness Website

A responsive, interactive website that spreads awareness about environmental protection, waste management, sustainability and eco-friendly practices.

Built as an individual project for the **Mid-Semester Examination (MSE) - Web Development and Cloud Foundation** (Problem Statement 4: *Environmental Awareness Website*).

🔗 **Live Website:** [https://YOUR-PROJECT-NAME.vercel.app](https://YOUR-PROJECT-NAME.vercel.app)
📁 **GitHub Repository:** [https://github.com/YOUR-USERNAME/YOUR-REPO-NAME](https://github.com/YOUR-USERNAME/YOUR-REPO-NAME)

---

## 🎯 Objective

To create a user-friendly website that makes people aware of major environmental problems and shows them simple, practical steps for a greener lifestyle, such as correct waste segregation, saving energy and water, and reducing plastic use.

---

## ✨ Features

- **Responsive design** - works on mobiles, tablets and laptops (hamburger menu on small screens)
- **Dark mode** - toggle button, and the choice is remembered after refresh
- **Animated statistics counters** - numbers count up when they scroll into view
- **Environmental issues section** - air pollution, water scarcity, deforestation and plastic waste
- **Photo gallery** with hover zoom effects
- **Waste handling guide** - click a bin (wet, dry, hazardous, e-waste) to see what goes in it
- **Eco tips with filters** - filter tips by Energy, Water or Waste
- **Carbon footprint calculator** - estimates monthly CO₂ emissions and gives advice
- **Green pledge form** - with JavaScript validation (name, email, pledge) and a saved pledge count
- **Back-to-top button** and smooth scrolling

## 🚀 Setup Instructions

Since this is a plain HTML/CSS/JS project, no installation is needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
   ```
2. **Open the project folder**
   ```bash
   cd YOUR-REPO-NAME
   ```
3. **Run the website** - double-click `index.html` to open it in your browser.
   (Optional: use the *Live Server* extension in VS Code for auto-refresh.)

> Keep `index.html`, `style.css`, `script.js` and the `images/` folder together in the same folder, otherwise styles and pictures will not load.

---

## 🌐 Deployment (Vercel)

1. Upload the project to a GitHub repository (with `index.html` in the root folder).
2. Log in to [Vercel](https://vercel.com) with GitHub.
3. Click **Add New → Project** and import this repository.
4. Keep the default settings (no build command needed) and click **Deploy**.
5. Vercel gives a public link, which is added at the top of this README.
